# Comment mettre à jour la documentation ?

La fonctionnalité de co-création dans Office permet désormais à plusieurs utilisateurs de travailler de manière productive sur le même document sans s’intruser sur le travail de l’autre ou se verrouiller mutuellement.

Vous pouvez utiliser cette nouvelle fonctionnalité de co-création dans PowerPoint, Word et OneNote documents sur SharePoint Server et OneDrive. De nouvelles fonctionnalités de co-édition sont également prises en charge dans Excel pour le web et OneNote pour le web. Pour en savoir plus sur les fonctionnalités de collaboration dans Word, consultez Collaborer sur des documents Word avec la co-création en temps réel

## Modifier la documentation

1. Ouvrir le dépôt du projet
2. Aller dans le dossier Ma Docu
3. Modifier ou créer un fichier MD
4. Enregistrer les changements ATTENTION

## Publier les changements

1. Valider les modifications avec gitGit
2. Envoyer les changements sur la branche principale IMPORTANT
