Définitions

Objectif : Définir des termes basiques du web

Liste des définitions

  1. HTTP : Protocole
  2. GET: Appartient à HTTP, c'est des méthodes quand on veut récupérer quelque chose exemples : POST, UPDATE, DELETE, PUT, HEAD
  3. DNS : Service
  4. Https:// : Pour secure, protocole de début d'URL
  5. URL : Unique Ressources Locator
  6. Dummyjson.com : Nom de domaine, top level domaine fourni par IAANA, il peut y avoir des sous domaine
  7. 443 : Port pour https, 80 c'est pour HTTP
  8. recipes : Nom de la ressource
  9. HTTP/2 : Version du protocole
  10. ? ; limit = 10 : le ? est un délimiteur, tout ce qui est après n'est pas une ressource mais des dictionnaires. Limite = paramètre de la ressource
